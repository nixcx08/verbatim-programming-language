# Verbatim Programming Language

Verbatim is a small, statically typed teaching programming language designed to promote explicit and predictable programming.

Its defining principle is that the compiler never guesses. Verbatim does not permit implicit type conversions or truthy values.

## Features

- Explicit variable declarations and type annotations
- Integer, Boolean, and string data types
- Array support
- Arithmetic and logical expressions
- Conditional statements
- While loops
- Function declarations and function calls
- Recursive functions
- Static type checking
- Explicit type conversions
- Error reporting

## Built-in Functions

- `print()` – Displays string values.
- `len()` – Returns the length of supported values.
- `str()` – Converts an integer into a string.
- `to_int()` – Converts a string into an integer.

## Technologies Used

- Python

## Project Structure

The repository contains the source code, implementation modules, and supporting files required to run and understand Verbatim.

## Project Purpose

Verbatim was developed as an academic programming language implementation project. It demonstrates the design and implementation of a small programming language, including lexical analysis, parsing, type checking, and program execution.
